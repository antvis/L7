# Administrative divisions

Download and explore administrative boundary data.

[Download maps](/en/tools/map/) · [GitHub](https://github.com/antvis/l7-extensions/tree/master/packages/district-data)

## Features

- **Data downloads**: Province, city and county boundaries, including historical versions.
- **Complete**: Explore maps online or use the data SDK and visualization components.
- **Convenient**: Export GeoJSON, JSON, TopoJSON, CSV, KML and SVG.

## Data fields

Select provinces, cities, counties or the world map, then export CSV or JSON.
